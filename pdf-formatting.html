PDF file formatting guide

Good formatting makes a document easier to read on screen and more predictable on paper. Start with the source, then check the PDF.

What PDF formatting means

PDF is the file format; formatting is the arrangement and appearance of the content inside it. Page size, margins, type, images and spacing all shape the reader’s experience. A PDF can preserve a layout, but it cannot automatically fix a poorly prepared source.

If the distinction is new, start with the PDF format explained.

Choose page size and orientation

Pick the page size before designing. A4 is common internationally; US Letter is common in the United States. Use portrait for most letters and reports, and landscape when a wide table or diagram genuinely needs the room.

Match any submission or print requirements. After export, check page dimensions in your PDF reader and use actual-size printing when precise dimensions matter.

Set margins and a consistent layout

Leave enough space around the page so text is comfortable to read and will not be clipped by a printer’s unprintable area. Use the source application’s margin and paragraph settings rather than repeated spaces or blank lines.

Keep headings, body text and page numbers consistent. On a long report, check that headings do not sit alone at the bottom of a page and that tables do not split in confusing places.

Fonts and text formatting

Choose readable fonts and a sensible body size. Use the source document’s styles for headings and body text, rather than manually changing every paragraph. When exporting, enable font embedding if the application offers it and the font license allows it.

Check that text is selectable and reads in a sensible order. For accessibility, use meaningful headings, sufficient contrast, descriptive links and properly tagged export where supported; test the finished PDF with assistive technology when possible.

Images and document quality

Use source images with enough resolution for their final size. For a photograph intended for high-quality print, around 300 pixels per inch at the placed size is a useful starting point; screen-only documents can often use less. Avoid repeatedly enlarging a small image.

Compression can reduce file size but may introduce artifacts or reduce readability. Keep the original, then inspect a compressed copy at normal viewing and print sizes.

Solve common formatting problems

  • Text wraps differently: check whether the intended fonts were embedded and export again from the original.
  • Content is cut off: verify page size, margins and printer scaling; cropping changes the visible area, not necessarily the underlying content.
  • Images are fuzzy: replace the source image with a higher-resolution version rather than enlarging the existing one.
  • Text cannot be selected: it may be a scan. Apply OCR if appropriate, then check for recognition errors.
