Format PDF: a practical guide

From an editable draft to a shareable file, a few deliberate checks can prevent most last-minute document surprises.

  • Meet common PDF formatting requirements

Understand the format before you export

When someone asks you to “format PDF,” they may mean create a PDF, improve its page layout or edit an existing file. First decide which result is needed. A PDF is a portable page-based format; formatting describes the way the content is laid out.

If you have the editable original, make substantial changes there. If you only have a PDF, what you can change depends on the file and the editor. See how PDF documents are assembled for why.

Prepare the source document

  1. Confirm the requirements. Check the requested page size, orientation, file size and any accessibility or archival standard.
  2. Use document styles. Apply consistent headings, paragraphs and lists, and add descriptive text for meaningful images where supported.
  3. Inspect the layout. Check page breaks, tables, captions, spelling and images at their intended size.
  4. Export to PDF. Choose the application’s export or save-as option and enable tagging and font embedding when available.

Meet common PDF formatting requirements

Use the specified paper size and margins rather than relying on the reader to scale the page. For a printable form, leave room for a printer’s unprintable edges. For a digital document, make text readable and ensure links and form fields work.

If a recipient asks for PDF/A or PDF/UA, use software that supports the requested standard and validate the output; an ordinary PDF is not automatically compliant. For more on spacing and image quality, visit the page formatting guide.

Keep layouts consistent

Embed fonts where permitted, use reliable source images and avoid building alignment with spaces. After export, compare the first and last pages with the source, then check pages containing tables or graphics. Open the file in a second reader if the handoff is important.

For print, inspect the print preview and confirm whether “actual size” or a scaling option is required.

Avoid common mistakes

  • Do not assume a PDF is accessible just because it looks correct; check tags, reading order and alternatives.
  • Do not overwrite your only editable copy with an exported file.
  • Do not assume cropping removes sensitive content. Use a proper redaction workflow and verify the result.
  • Do not compress blindly: some methods reduce image quality or flatten text and form fields. Inspect the output.
  • Do not share an outdated draft: use a clear file name and confirm the recipient.

Manage files after export

Use a consistent naming pattern such as project-report-2026-11-final.pdf. Keep source and final files in an organized folder, and retain older versions only as long as needed. Before uploading sensitive files to any service, review its privacy and retention terms.
