Understanding PDF documents

A closer look at what is inside a PDF file, from its page instructions to the text and images you see.

What is a PDF document?

A PDF document is a file that describes one or more pages for viewing or printing. The pages might contain an invoice, a slide deck or a scanned letter. The .pdf extension identifies the format, but two PDFs can be built in very different ways.

For the broader history and trade-offs, see what makes the PDF format portable.

How PDF files work

A PDF reader interprets instructions in the file and draws the result on screen or sends it to a printer. The file may include text characters, vector shapes and raster images, as well as information about their position, size and appearance.

A page can also have annotations, links or form fields. A viewer must support a feature to display or use it as intended; not every viewer behaves identically.

A simple view of file structure

Under the hood, a PDF contains numbered objects: for example, objects can describe pages, fonts, images and other resources. References connect those objects. A cross-reference mechanism helps a reader locate them, and trailer information points to key parts of the file.

You do not need to inspect these internals to use a PDF. The practical lesson is that a page is assembled from pieces—it is not necessarily a single flat picture or an editable word-processing document.

Text, images, fonts and layout

Text and fonts

Text may be stored as characters positioned on a page, using embedded fonts or fonts a viewer substitutes. A scan, by contrast, may contain only a picture of text. OCR can add a searchable text layer, but its accuracy needs review.

Images and graphics

Photos and scans are commonly stored as raster images; diagrams and line art may be vector graphics. Raster images can become blurry when enlarged, while vector shapes generally remain sharp. A file may contain both.

Layout and reading order

Page instructions control visual placement. Tags and a logical reading order can help assistive technology interpret content, but they are not present or correct in every PDF.

Why the same PDF looks similar

Fixed page geometry and embedded resources help viewers reproduce the same layout. Variation is still possible, especially when fonts are missing, transparency is interpreted differently or a feature is unsupported. Printing settings such as “fit to page” can also change the output size.

Before sharing, check the file at normal size, select some text and inspect any forms. For more checks, read the formatting troubleshooting section.

Common uses

People send PDFs when a finished appearance matters: contracts for review, printable forms, invoices, reports and reference manuals. When several people must substantially revise the same text, an editable source file is often more convenient.
