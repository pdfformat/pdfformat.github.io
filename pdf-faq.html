Common PDF questions

Straightforward answers to the questions that come up when opening, sharing and working with PDF files.

On this page

PDF basics

What does PDF format mean?

PDF means Portable Document Format. It is a file format designed to represent documents consistently across applications and devices. A PDF file usually ends in .pdf. Read more about PDF and its history.

Why is PDF used for documents?

It is widely supported and generally preserves page layout, making it useful for sharing, printing and storing finished documents. The result can still vary when fonts are missing or a viewer does not support a feature.

Is PDF better than Word for sharing documents?

It depends. PDF is often a good choice for a finished layout; a Word document is often better when the recipient needs to make extensive edits. Follow the recipient’s format and accessibility requirements.

Can a PDF file contain images?

Yes. PDFs can contain photos, scans, diagrams and text. Some scanned PDFs are essentially page images and may need OCR before their text can be searched or selected.

What is the difference between PDF and other document formats?

PDF emphasizes a portable page presentation. Formats such as DOCX are generally designed for editing and reflowing text. Image formats like JPEG store pictures rather than the same combination of page content and document structure.

Opening and formatting

How do I open a PDF file?

Open it in a current web browser or a trusted PDF reader. On a phone, the built-in file viewer may work. If it will not open, check that the download completed and that the file is from a trusted source.

Why does PDF formatting change?

Missing fonts, export settings, viewer differences or print scaling can alter the result. Check the original, embed fonts when possible and inspect the exported file. The formatting guide has a troubleshooting checklist.

Can I edit a PDF?

Many PDFs can be edited with suitable software, but complex layouts and scans can be difficult. If you have the original, making changes there and exporting again often produces a cleaner result.

Managing and sharing files

How can I reduce a PDF file size?

Try exporting with a smaller-file setting or compressing a copy, especially if the file contains large images. Compare the output with the original: some compressors reduce image quality or flatten text and interactive fields.

Can I combine multiple PDF documents?

Yes. A PDF organizer or merger can combine pages into one file. Check the page order, orientation and final size, and retain the originals in case you need to make changes.

Is a PDF automatically secure or accessible?

No. Permissions and encryption vary, and visual formatting alone does not create accessible tags or reading order. Use appropriate security, check accessibility and verify redactions before sharing.
